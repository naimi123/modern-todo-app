# ✅ Modern To-Do App

A modern, fully responsive To-Do application built with **HTML**, **CSS**, and **vanilla JavaScript**.

## ✨ Features

- ➕ **Add tasks** with title
- ✔️ **Mark tasks as complete** / uncomplete
- 🗑️ **Delete tasks** individually
- 🔍 **Filters**: All / Active / Completed
- 💾 **LocalStorage** — your tasks persist after closing the browser
- 🌙 **Dark Mode** toggle
- 🔢 **Live task counter**
- 🧹 **Clear all completed** tasks at once
- 📱 **Responsive** — works on mobile, tablet and desktop

## 📁 Project Structure

```
modern-todo-app/
├── index.html   # Main HTML page
├── style.css    # Modern styling + dark mode
├── script.js    # App logic (CRUD, storage, filters)
└── README.md    # This file
```

## 🚀 How to Run

1. Clone the repository:
   ```bash
   git clone https://github.com/naimi123/modern-todo-app.git
   ```
2. Open `index.html` in your browser — no build step, no dependencies.
